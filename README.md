## 💻 How to View & Run Locally
Because this portfolio is built with modern vanilla web standards and CDN-backed resources, it requires **zero build steps or compilation**.

### Option 1: Direct Double Click
Simply double-click `index.html` in Windows Explorer to open it in your default web browser (Chrome, Edge, Brave, Firefox, etc.).

### Option 2: Local HTTP Server (Recommended)
Using Python or Node.js:

**With Node.js (npx):**
```bash
npx serve .
# or
npx http-server .
```

**With Python:**
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
